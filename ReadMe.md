# TestProject

Простое iOS-приложение на **Swift + UIKit**, реализованное в рамках тестового задания.  
Показывает базовый флоу с онбордингом, paywall и сохранением состояния подписки.

---

## Функциональность

- **Onboarding**
  - Один экран с кнопкой «Продолжить»

- **Paywall**
  - Два тарифа:  
    - Месяц — 99 ₽  
    - Год — 713 ₽ (скидка 40%)
  - Покупка эмулируется (без реального биллинга)

- **Главный экран**
  - Простой список (UITableView)

- **Сохранение состояния**
  - Статус подписки хранится в `UserDefaults`
  - При повторном запуске сразу открывается главный экран
